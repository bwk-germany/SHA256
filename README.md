### Was ist SHA256?
Die Integrität einer Datei kann mithilfe des weit verbreiteten SHA-256-Algorithmus überprüft werden. Eine Datei kann dabei auch das Inhaltsverzeichnis eines Dateiverzeichnisses sein.

SHA steht für Secure Hash Algorithm (sicherer Hash-Algorithmus).
Die Zahl 256 steht für 256 Bit.

Acht Bit bilden ein Byte. Somit entsprechen 256 Bit insgesamt 32 Byte.

In der Dezimalschreibweise kann ein Byte einen Wert zwischen 0 und 255 annehmen. In der Hexadezimalschreibweise (bei der auf die Ziffer 9 die Buchstaben a bis f folgen) kann ein Byte durch zwei Zeichen (0–9, a–f) dargestellt werden.

Aus diesem Grund ist der Hashwert für 32 Byte insgesamt 64 Zeichen lang. Die SHA-256-Ausgabe sieht beispielsweise wie folgt aus:

8d23cf6c86e834a7aa6eded54c26ce2bb2e74903538c61bdd5d2197997ab2f72
